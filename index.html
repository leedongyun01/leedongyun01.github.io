Troubleshooting & Engineering Notes

실제 프로젝트에서 발생한 원인 분석과 문제 해결의 수식적/논리적 기록

Troubleshooting ProbeAI / Race Condition

에이전트 간 비동기 상태 동기화 및 덮어쓰기 이슈 해결

[문제] AI 리서치 진행 시 에이전트의 비동기 상태 업데이터가 Supabase 타이밍 차이로 이전 상태를 덮어쓰는 Race Condition 발생.
[분석] 상태 변경 시 현재 검증 로직이 빠져 있어 이전 비동기 작업이 완료되면 새 상태가 파괴됨.
[해결] `lib/orchestrator.ts`에 유효 상태 전이 맵(`LEGAL_TRANSITIONS`)을 구현하고 상태 갱신 전 엄격 검증 도입으로 100% 정합성 확보.

Validation Guard LLM Hallucination

LLM 본문 출처 인용구 오류 및 환각(Hallucination) 검증기 도입

[문제] 합성 단계에서 생성된 보고서에 존재하지 않는 출처 소스 ID가 추가되는 환각 현상 관찰.
[분석] 컨텍스트 토큰 누적으로 인한 프롬프트 지시사항 희석.
[해결] Post-processing 단계에 `Citation Validator` 후처리기를 배치하여 출처 ID 검증 및 프롬프트에 엄격 가이드라인 강제.
