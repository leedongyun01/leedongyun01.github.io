Troubleshooting & Engineering Notes

실제 프로젝트에서 해결한 개발 문제 분석 및 원인 규명

Optimization GiftTrip / TTL Cache

OpenAI API 호출 비용 및 지연 시간(Latency) 문제 극복

[문제] 사용자 코스 생성 요청마다 외부 OpenAI API를 동기 호출하여 응답 지연(최대 5초) 및 API 토큰 비용 급증.
[분석] 동일하거나 유사업종/국가 추천 요청에 대한 데이터 재활용 체계 부재.
[해결] `ReviewEngine.cjs` 내 인메모리 TTL 캐싱 엔진을 구축하여 자주 쿼리되는 여행지 데이터를 캐싱함으로써 Latency 80% 단축 및 API 비용 절감.

Security & Infra CollabMate / Auth

동적 환경 분리(.env) 및 JWT 기반 클라이언트 자동 인증 구현

[문제] 배포 환경(AWS EC2/RDS)과 로컬 개발 환경 전환 시 하드코딩된 API 엔드포인트 및 DB 접속 정보로 인한 인증 오류 발생.
[분석] 환경 변수 통합 관리 미흡 및 API 요청 시 토큰 유실.
[해결] 단일 소스코드 상에서 `.env` 주입 체계를 구축하고, Axios Interceptor 미들웨어를 통해 API 요청 헤더에 JWT 토큰 자동 주입 및 자동 갱신.
